# Student Grade Tracker

A Java-based application for managing student academic records.

## Features

- Add and view student records
- Search for students
- Calculate class averages
- Identify the highest score
- Save and load records using file handling

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- File I/O
- Scanner

## What I Learned

This project helped me develop my understanding of Java programming, object-oriented design, data management, and file handling.
